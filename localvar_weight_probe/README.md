# localvar_weight_probe

局部方差 + 温度 Softmax 动态权重方案的原理验证实验。在接入融合网络之前，用纯统计方法（numpy/OpenCV）确认该方案的三个前提成立。

## 1. 动机：传统最大值包络的问题

红外/可见光融合中，经典的"取最大值包络"按局部统计量（如梯度能量、方差）逐像素二选一：

```text
W_ir = I(V_ir > V_vi)    （指示函数，0/1 硬分配）
```

从统计学视角看，这是把权重退化成只有 0 和 1 的伯努利分布，完全丢弃了两个模态统计量之间的相对差距信息。它带来两个问题：

1. **梯度场非连续跳跃**：在 V_ir 与 V_vi 领先关系翻转的位置，权重从 0 跳到 1，融合图像的梯度场在这些交界处突变，视觉上表现为块状/盐椒伪影（可在 fig4 硬 max 面板的植被区域直接观察到）。
2. **信息抹杀**：当两个模态在该区域都有细节（V_ir ≈ V_vi）时，硬分配直接丢弃其中一方，而不是混合。

## 2. 方法：局部方差 + 温度 Softmax

### 2.1 局部方差 = 局部高频能量的代理

对灰度图 x，在 win×win 窗口内计算总体方差（box filter 实现，reflect 边界填充）：

```text
V = E[x²] − E[x]²
```

方差直接等价于该窗口的高频能量/信息熵：纹理复杂或边缘锐利的区域方差大，平坦区域方差接近 0。相比 Sobel，方差对窗口内所有方向的高频结构都响应，且是"能量"度量（对对比度二次敏感）。

**量纲约定**：方差图按最大值归一化到 [0,1] 后再进入 Softmax，τ 定义在归一化尺度上。

### 2.2 温度权重（玻尔兹曼分布视角）

用统计物理中的玻尔兹曼分布（即 Softmax）替代硬指示函数：

```text
W_ir = exp(V_ir/τ) / (exp(V_ir/τ) + exp(V_vi/τ))
W_vi = 1 − W_ir
```

τ 是温度参数，控制权重分配的"软硬程度"，具有严格的极限行为：

| τ 取值 | 权重行为 | 等价操作 |
| --- | --- | --- |
| τ → 0 | 分布逼近狄拉克 δ，权重退化为 argmax | 传统最大值包络（硬分配） |
| τ → ∞ | 分布逼近均匀分布，权重 → 0.5 | 简单梯度/像素平均 |
| 中间值 | 连续混合：V 差距大时权重接近 1/0，V 接近时平滑过渡 | 稳健的软选择 |

关键性质：当 V_ir 远大于 V_vi 时权重趋向 1（行为接近硬包络，不损失显著结构）；当两者接近（都有细节）时给予平滑的混合权重而非粗暴二选一——这正是对硬分配所丢弃的"联合分布信息"的恢复。

## 3. 验证设计与结论

脚本对每张测试图输出四组图（本实验为定性验证）：

| 图 | 内容 | 验证问题 | 结论 |
| --- | --- | --- | --- |
| fig1 | 灰度 \| 局部方差 \| Sobel \| Canny 四联 | 方差能否提取纹理与边缘 | **能**。方差图与 Sobel/Canny 高亮区域空间一致；方差因窗口呈更厚团状、对对比度二次敏感 |
| fig2 | V_ir、V_vi 及各 τ 的 W_ir/W_vi（同色图，红=1 蓝=0） | 极限行为与互补性 | τ=0.05 近似二值 argmax；τ=1000 全图 0.5；中间单调平滑；W_vi = 1−W_ir 严格互补 |
| fig3 | 梯度域融合：`fused_grad = W·‖∇IR‖ + (1−W)·‖∇VI‖`，硬 max vs 软 τ=0.5 | 权重作用于梯度场的效果 | 软权重抑制高纹理区的孤立单模态尖峰、边界更平滑 |
| fig4 | 图像域融合：`F = W·IR + (1−W)·VI`，附 IR/VI 原图 | 端到端融合效果与伪影 | 软 τ=0.5 基本消除硬 max 的块状伪影，红外亮目标（行人）与可见光纹理（植被）同时保留 |

### fig3 梯度域融合的原理

fig3 是诊断图，展示"融合后的梯度场"：先对两模态各算 Sobel 梯度幅值，再按权重逐像素选择/混合——**谁的局部方差大（高频能量高），就保留谁的梯度**。硬权重在方差领先关系翻转处产生梯度场突变（即 §1 所述伪影来源）；软权重用 τ 平滑该切换。注意 fig3 不做 base + 梯度重建，真正的图像级效果看 fig4。

### τ 的有效区间（归一化方差尺度）

- **τ ∈ [0.05, 0.5]**：有信息量的工作区间，兼顾空间自适应与平滑性
- **τ ≥ 10**：视觉上退化为常数 0.5（等权平均），失去模态选择能力
- 网络模块中 τ 的初始化建议取该区间内（如 0.1~0.5）

## 4. 使用范围与限制

**适用：**

- 红外/可见光融合中替代硬 max 包络的权重设计（梯度域选择、图像域加权均可）
- 可直接嵌入网络：`local_variance` 与 `temp_weight` 均为可微分算子（box filter 可用 conv/avg_pool 实现，Softmax 天然可微），τ 可设为可学习参数
- 需要平滑模态切换、抑制交界伪影的场景

**限制与已知权衡：**

- 方差对对比度**二次敏感**：会压低弱对比结构（如夜间磨旧车道线）相对 Sobel 的响应——若目标场景以弱对比细节为主，需考虑方差的开方或与梯度幅值联合
- τ 依赖归一化尺度：换数据集/动态范围时有效 τ 区间可能平移，建议按本脚本的归一化约定使用
- 窗口 win 是感受野超参：win=7 偏向细纹理；更大窗口更稳健但边缘定位变厚
- 本实验只做了定性验证；接入网络前如需定量支撑，可补充 W_ir 与梯度幅值图的 Pearson 相关、各 τ 下 mean(W_ir) 曲线等指标
